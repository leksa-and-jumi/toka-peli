# Toka peli 🎮

Juliuksen toinen peli.

Julius suunnittelee, Claude rakentaa.

## Pelaa

Peli julkaistaan GitHub Pagesiin aina, kun uusi versio valmistuu.

👉 **[Pelaa tästä!](https://leksa-and-jumi.github.io/toka-peli/)**

## Miten pelataan

- Liiku **nuolinäppäimillä**.
- Kerää **keltaisia tähtiä**. Jokaisesta saa pisteen.

_Tämä on aloituspohja. Julius päättää, millainen oikeasta pelistä tulee!_
